# Chakra and Elements Toning (Mantra)

A meditation app for Android built on DJ Mantra's chakra toning: a guided toning with MilkDrop visuals, five element
stripes to sing along (A, U, I, O, A-U-I-O), a breath circle, a session timer with a soft bell, background play and a
gentle practice log. Offline, no account, no internet permission.

Download the latest version: https://github.com/markoboskoauroville/CHAKRA_ELEMENTS_TONING/releases/latest
