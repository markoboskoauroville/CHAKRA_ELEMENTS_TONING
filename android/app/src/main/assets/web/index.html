The five elements
Earth, A, the root, gold. Water, U, below the navel, milky white. Fire, I, the navel, crimson. Air, O, the heart, green. Ether, A-U-I-O, the throat, all colours. Sing the vowel with the voice, on one breath, and let the next breath come by itself.
